# Knowledge Vault

Bu qovluq layihə üçün uzunmüddətli yaddaş və qərar bazasıdır.

## Struktur
- `00-Inbox` — tez capture edilən xam qeydlər
- `01-Daily` — gündəlik iş qeydləri
- `02-Projects` — feature/epic mərkəzli qeydlər
- `03-Decisions` — ADR/texniki qərarlar
- `04-Runbooks` — əməliyyat runbook qeydləri
- `99-Archive` — köhnə, passiv qeydlər
- `Templates` — standart qeyd şablonları

## Workflow (qısa)
1. Yeni fikir və ya müşahidəni `00-Inbox`-a yaz.
2. Gün sonunda dəyərlilərini `02-Projects` və `03-Decisions`-a köçür.
3. Təkrarlanan əməliyyatları `04-Runbooks`-a standartlaşdır.
