# ADR-001: In-project Obsidian Vault

- Date: 2026-05-04
- Status: Accepted

## Context
Layihə içində operativ qərarlar və deploy bilikləri chat tarixçəsində dağınıq qalırdı.

## Decision
Repo daxilində `Knowledge/` və `.obsidian/` ilə yüngül Obsidian vault quruldu.

## Consequences
- Qərarların və runbook biliklərinin təkrar istifadəsi artacaq.
- Team context switch zamanı məlumat itkisi azalacaq.

## Follow-up Actions
- Deploy və verification checklist-ləri runbook formatında doldur.
- Daily notes ritmini aktiv et.
